# Agent Spec: Weather & Outfit Advisor

## Overview
Weather & Outfit Advisor is a lightweight conversational agent designed to help users prepare for their day. Given a location (e.g., city name), the agent looks up the weather conditions and temperature, and provides practical, friendly clothing and accessory recommendations (e.g., coats, umbrellas, sunglasses, layers).

## Language
`python`

## Example Use Cases
1. **User**: "What should I wear today in Seattle?"
   * **Tool Call**: `get_weather(location="Seattle")` -> `{"temperature": 55, "condition": "rainy"}`
   * **Agent Response**: "In Seattle today, it's 55°F and rainy. I recommend wearing a waterproof jacket or raincoat, comfortable boots, and bringing an umbrella!"

2. **User**: "Is it warm enough for shorts in Miami?"
   * **Tool Call**: `get_weather(location="Miami")` -> `{"temperature": 82, "condition": "sunny"}`
   * **Agent Response**: "Yes! Miami is currently 82°F and sunny. Shorts, a t-shirt, and sunglasses are perfect for today."

## Tools Required
* `get_weather`: Takes a city/location string and returns mock or live weather data (temperature in Fahrenheit/Celsius, weather condition like sunny, rainy, cold, windy).

## Constraints & Safety Rules
* Must always look up weather data using `get_weather` before offering specific outfit advice.
* Provide advice tailored directly to temperature ranges (e.g. <50°F = heavy coat/warm layers, 50-70°F = jacket/sweater, >70°F = light clothing) and weather conditions (e.g. rain = umbrella/waterproofs).
* Stay polite, helpful, and concise.

## Success Criteria
* 100% tool invocation rate when asked for weather or outfit advice in a specific location.
* Accurately matches outfit suggestions to the temperature and weather conditions returned by the tool.
